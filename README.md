# QuickPoll v1.0

QuickPoll is a cinematic, glass-styled poll web app that lets users create and share polls instantly — no sign-up required.

Built with pure HTML, CSS, and Vanilla JavaScript.

---

## ✨ Features

- 🌌 Animated starfield background with mouse parallax
- ✨ Visible twinkling stars
- ☄ Frequent shooting stars (2–4 seconds)
- 🌠 Rare cinematic super-comet effect
- 🗳 Create polls with up to 4 options
- ❌ Remove extra options easily
- 📊 Live vote percentage bars
- 👤 Voter name tracking (stored locally)
- 📎 Shareable link system
- 📋 Copy link with feedback
- 🔐 Custom confirmation modal (Reset / New Poll)
- 💾 LocalStorage persistence
- 🎨 Glassmorphism UI with seamless diagonal wave animation

## 🎯 Design Goals

QuickPoll was built with a focus on:

- Visual depth & cinematic experience
- Clean UI with smooth micro-interactions
- Zero external backend
- Lightweight and fast
- Structured modular code

---

## 🧠 What Makes It Different?

Unlike basic poll apps, QuickPoll integrates:

- A layered animated space background
- Dynamic shooting stars & rare comet events
- Mouse-responsive parallax
- Custom modal system (no default browser alerts)
- Fully local persistent poll state
